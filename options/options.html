Available variables: {datetime}, {title}, {url}, {domain}, {subdomain}, {type}

  • {datetime}: Current date and time
  • {title}: Page title
  • {url}: Full hostname (e.g., www.example.com)
  • {domain}: Base domain without TLD (e.g., “example” from “www.example.com”)
  • {subdomain}: Subdomains with base domain (e.g., “www_example” from “www.example.com”)
  • {type}: VP viewport, DL delayed, FS full page, RG region
